📝 需要你完成的步骤
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

□ 1. 创建 GitHub OAuth 应用
     网址：https://github.com/settings/developers
     回调：https://lemonix.loc.cc/api/oauth/github/callback
     记录：Client ID 和 Client Secret

□ 2. SSH 连接服务器
     命令：ssh root@<你的服务器IP>

□ 3. 安装 Docker（如果未安装）
     命令：curl -fsSL https://get.docker.com | sh

□ 4. 克隆项目
     命令：git clone <仓库地址> lab-reservation-system

□ 5. 配置 .env 文件
     命令：cp .env.example .env && nano .env
     填写：上面的密钥 + GitHub OAuth 信息

□ 6. 配置邮箱
     命令：nano init-ssl.sh
     修改：EMAIL="your-email@example.com"

□ 7. 执行部署
     命令：chmod +x init-ssl.sh update.sh && ./init-ssl.sh

□ 8. 首次登录获取 openId
     访问：https://lemonix.loc.cc
     查看：docker compose logs app | grep "openId"

□ 9. 配置管理员
     命令：nano .env
     填写：OWNER_OPEN_ID=github-xxxxxx
     重启：docker compose restart app

□ 10. 验证部署
     访问：https://lemonix.loc.cc
     测试：登录、创建预约等功能
