# 账号注销说明

## 概述

用户可以通过"账号设置 → 注销账号"功能永久删除自己的账号。此操作不可撤销，请谨慎使用。

---

## 注销 vs 黑名单

系统提供两种限制机制，适用于不同场景：

| 功能 | 注销账号 | 黑名单 |
|------|---------|--------|
| **触发方式** | 用户主动申请 | 管理员添加 |
| **用途** | 永久退出系统 | 临时限制违规用户 |
| **数据处理** | 删除所有个人数据 | 保留数据，限制功能 |
| **能否登录** | 可以（作为新用户重新注册） | 可以登录，但不能预约 |
| **能否重新注册** | ✅ 可以，作为全新用户 | ❌ 黑名单期间不能预约 |
| **数据恢复** | ❌ 不可恢复 | ✅ 解除黑名单后恢复功能 |
| **适用场景** | 毕业离校、不再使用 | 违约处罚、临时限制 |

### 重要说明

**注销后可以重新注册：**
- 用户注销账号后，可以使用相同的 OAuth 账号（GitHub/QQ）重新登录
- 重新登录时系统会自动创建新账号（作为全新用户）
- 之前的数据不会恢复，角色根据白名单自动分配
- **适用场景**：学生毕业后注销账号，几年后回校读研可以重新注册

**黑名单机制：**
- 用于管理违约用户，限制其预约功能
- 黑名单用户可以登录，但不能创建新预约
- 管理员可以设置黑名单期限或永久限制
- 解除黑名单后，用户恢复正常功能

**如何选择：**
- 用户想永久退出 → 使用注销功能
- 管理员要惩罚违规 → 使用黑名单功能
- 需要"封禁"用户 → 使用永久黑名单

## 注销方式

### 用户自主注销

1. 登录系统
2. 点击右下角用户头像
3. 选择"注销账号"
4. 阅读警告信息
5. 输入确认文本："删除我的账号"
6. 勾选"我理解此操作不可撤销"
7. 点击"注销账号"按钮
8. 最终确认对话框中点击"确认注销"

### 管理员删除用户

管理员可以在"用户管理"页面删除其他用户（但不能删除自己）。

## 注销后的影响

### 立即删除的数据

注销账号后，以下数据将被**永久删除**：

#### 1. 用户基本信息
- ✅ 用户名、邮箱等个人信息
- ✅ 用户 ID 和 OpenID
- ✅ 登录凭证和会话

#### 2. OAuth 绑定
- ✅ 所有 OAuth 账号绑定（GitHub、QQ 等）
- ✅ Access Token 和 Refresh Token

#### 3. 预约记录
- ✅ 所有个人预约记录
- ✅ 预约申请、审批历史
- ✅ 改签记录

#### 4. 通知消息
- ✅ 所有系统通知
- ✅ 预约提醒
- ✅ 审批通知

#### 5. 违约记录
- ✅ 违约记录
- ✅ 黑名单记录

#### 6. 学生相关
- ✅ 课程选课记录
- ✅ 班级成员关系
- ✅ 课堂出勤记录

---

### 保留或转移的数据

以下数据不会被删除，而是被**保留**或**转移**：

#### 1. 审计日志（保留）
- ⚠️ **保留所有审计日志**
- 原因：用于系统审计和合规要求
- 影响：管理员仍可查看历史操作记录
- 数据匿名化：用户 ID 保留，但用户信息已删除

#### 2. 教师创建的课程（归档）
- ⚠️ **课程不会被删除**
- 处理方式：标记为"已归档"状态
- 原因：课程可能有其他学生选课
- 建议：注销前先转移课程给其他教师

#### 3. 签到会话（关闭）
- ⚠️ **签到会话不会被删除**
- 处理方式：标记为"已关闭"状态
- 原因：保留历史签到记录

## 注销前的准备

### 学生用户

1. **取消所有待审核的预约**
   - 避免影响实验室资源分配
   - 避免产生违约记录

2. **完成所有进行中的预约**
   - 确保没有未完成的实验室使用

3. **退出所有课程**
   - 联系教师退课
   - 避免影响课程管理

4. **备份重要数据**
   - 导出预约记录
   - 保存重要通知

### 教师用户

1. **转移课程管理权**
   - 将课程转移给其他教师
   - 或者归档不再使用的课程

2. **关闭所有签到会话**
   - 确保没有进行中的签到

3. **通知学生**
   - 告知学生课程变更
   - 提供新的联系方式

4. **导出教学数据**
   - 导出学生名单
   - 导出出勤记录
   - 导出成绩数据

### 管理员用户

⚠️ **管理员账号不建议注销**

如果必须注销：
1. 转移管理员权限给其他用户
2. 确保系统至少有一个管理员
3. 完成所有待处理的审批
4. 导出系统数据和报表

## 技术实现

### 数据库操作

注销账号时，系统会执行以下操作（使用事务确保一致性）：

```sql
BEGIN TRANSACTION;

-- 1. 删除 OAuth 绑定
DELETE FROM user_oauth_bindings WHERE userId = ?;

-- 2. 删除预约记录
DELETE FROM lab_reservations WHERE userId = ?;

-- 3. 删除通知
DELETE FROM notifications WHERE userId = ?;

-- 4. 删除违约记录
DELETE FROM violation_records WHERE userId = ?;

-- 5. 删除黑名单
DELETE FROM blacklist WHERE userId = ?;

-- 6. 删除课程学生关联
DELETE FROM course_students WHERE studentId = ?;

-- 7. 删除班级学生关联
DELETE FROM class_students WHERE studentId = ?;

-- 8. 删除出勤记录
DELETE FROM course_attendances WHERE studentId = ?;

-- 9. 归档教师课程
UPDATE courses SET status = 'archived' WHERE teacherId = ?;

-- 10. 关闭签到会话
UPDATE checkin_sessions SET status = 'closed' WHERE teacherId = ?;

-- 11. 删除用户记录
DELETE FROM users WHERE id = ?;

COMMIT;
```

### API 端点

```typescript
// 用户自己注销账号
trpc.user.deleteMyAccount.useMutation()

// 管理员删除用户
trpc.user.delete.useMutation({ id: userId })
```

## 安全措施

### 1. 多重确认

- 输入确认文本
- 勾选理解声明
- 最终确认对话框

### 2. 审计日志

注销操作会记录审计日志：
- 操作时间
- 操作 IP
- 用户信息
- 删除原因

### 3. 事务保护

使用数据库事务确保：
- 要么全部删除成功

- 不会出现部分删除的情况

### 4. 会话清除

注销后立即清除：
- Cookie 会话
- 前端缓存
- 重定向到登录页

## 常见问题

### Q1: 注销后可以恢复吗？

**不可以。** 注销是永久性操作，所有数据将被删除且无法恢复。

### Q2: 注销后可以重新注册吗？

**可以。** 使用相同的 OAuth 账号（GitHub/QQ）重新登录会创建新账号，但不会恢复旧数据。

### Q3: 注销后审计日志还在吗？

**是的。** 审计日志会保留，但用户信息已删除，只保留用户 ID 用于审计追踪。

### Q4: 教师注销后课程怎么办？

课程会被标记为"已归档"状态，不会被删除。建议注销前先转移课程给其他教师。

### Q5: 注销后预约记录还在吗？

**不在。** 所有预约记录会被删除。如果需要保留，请在注销前导出。

### Q6: 管理员可以恢复被删除的账号吗？

**不可以。** 即使是管理员也无法恢复已删除的账号。

### Q7: 注销需要多长时间？

通常在几秒内完成。系统会使用数据库事务确保数据一致性。

### Q8: 注销失败怎么办？

如果注销失败，请联系系统管理员。可能的原因：
- 数据库连接问题
- 外键约束冲突
- 权限不足

## 数据保护合规

### GDPR 合规

根据 GDPR（通用数据保护条例）：
- ✅ 用户有权删除个人数据（被遗忘权）
- ✅ 系统提供自助注销功能
- ✅ 审计日志保留符合合规要求
- ✅ 数据删除不可恢复

### 数据保留政策

- **个人信息**：立即删除
- **审计日志**：保留 7 年（合规要求）
- **归档课程**：保留至学期结束
- **匿名统计**：可能保留用于系统分析

## 开发者注意事项

### 添加新的关联表

如果添加了新的用户关联表，需要更新 `deleteUserAccount` 函数：

```typescript
// server/db.ts
export async function deleteUserAccount(userId: number) {
  await db.transaction(async (tx) => {
    // ... 现有删除逻辑
    
    // 添加新表的删除逻辑
    await tx.delete(newTable).where(eq(newTable.userId, userId));
  });
}
```

### 外键约束

确保数据库外键设置正确：
- 使用 `ON DELETE CASCADE` 自动删除关联数据
- 或在代码中手动处理删除顺序

注销功能需要充分测试：
- 单元测试：验证所有数据被删除
