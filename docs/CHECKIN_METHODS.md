# 签到方式说明

系统支持三种签到方式，适用于不同的场景。

## 1. 扫码签到（qrcode）

**适用场景**：课堂签到

**工作流程**：
1. 教师在课堂签到页面开启签到会话
2. 系统生成动态二维码（可设置刷新间隔，默认30秒）
3. 学生扫描二维码进行签到
4. 可选启用地理围栏验证位置

**特点**：
- 防止代签：二维码定时刷新
- 位置验证：可选启用地理围栏
- 迟到检测：自动计算迟到时间
- 适合集中签到场景

**相关页面**：
- 教师端：`/teacher/checkin` - 课堂签到管理
- 学生端：`/student/checkin` - 我的签到记录
- 扫码页面：`/scan?token=xxx` - 扫码签到

## 2. 地理围栏签到（geofence）

**适用场景**：个人预约签到

**工作流程**：
1. 用户创建预约并获得审批
2. 到达预约时间窗口（开始前15分钟至结束时间）
3. 点击签到按钮，系统自动获取位置
4. 验证位置是否在实验室地理围栏范围内
5. 验证通过后完成签到

**特点**：
- 位置验证：必须在围栏范围内
- 自动降级：如果未配置围栏或获取位置失败，自动降级为手动签到
- 防止远程签到：确保用户在现场
- 适合个人预约场景

**相关页面**：
- `/my-reservations` - 我的预约（签到/签退）
- `/geofence` - 地理围栏管理（管理员）

**地理围栏配置**：
- 中心点：实验室经纬度坐标
- 半径：允许签到的范围（米）
- 状态：启用/禁用

## 3. 手动签到（manual）

**适用场景**：
- 地理围栏签到失败时的降级方案
- 管理员手动标记出勤
- 特殊情况处理

**工作流程**：
1. 自动降级：当获取位置失败或未配置围栏时自动使用
2. 手动标记：教师在课堂签到页面手动更新学生出勤状态

**特点**：
- 无位置验证
- 灵活性高
- 适合特殊情况

## 签到方式对比

| 特性 | 扫码签到 | 地理围栏签到 | 手动签到 |
|------|---------|------------|---------|
| 位置验证 | 可选 | 必须 | 无 |
| 防代签 | 强（动态二维码） | 强（位置验证） | 弱 |
| 适用场景 | 课堂集中签到 | 个人预约 | 降级/特殊情况 |
| 自动化程度 | 高 | 高 | 低 |
| 用户体验 | 好（扫码快速） | 好（自动获取位置） | 一般 |

## 签到时间窗口

### 个人预约签到
- 开始时间：预约开始前15分钟
- 结束时间：预约结束时间
- 超时未签到：根据审批配置自动取消并记录违约

### 课堂签到
- 开始时间：教师开启签到会话
- 结束时间：教师关闭签到会话
- 迟到判定：可配置允许迟到分钟数（默认15分钟）

## 签到数据记录

每次签到都会记录以下信息：
- 签到时间
- 签到方式（qrcode/geofence/manual）
- 位置信息（如果有）
- 设备信息（User-Agent）
- 位置验证结果

这些信息会保存在审计日志中，可在审计日志页面查看详情。

## 技术实现

### 地理围栏距离计算

使用Haversine公式计算两点间的球面距离：

```typescript
function calculateDistance(
  lat1: number, lng1: number,
  lat2: number, lng2: number
): number {
  const R = 6371e3; // 地球半径（米）
  const φ1 = lat1 * Math.PI / 180;
  const φ2 = lat2 * Math.PI / 180;
  const Δφ = (lat2 - lat1) * Math.PI / 180;
  const Δλ = (lng2 - lng1) * Math.PI / 180;

  const a = Math.sin(Δφ/2) * Math.sin(Δφ/2) +
            Math.cos(φ1) * Math.cos(φ2) *
            Math.sin(Δλ/2) * Math.sin(Δλ/2);
  const c = 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1-a));

  return R * c; // 返回距离（米）
}
```

### 位置获取

使用浏览器Geolocation API：

```typescript
navigator.geolocation.getCurrentPosition(
  (position) => {
    const { latitude, longitude } = position.coords;
    // 使用位置信息签到
  },
  (error) => {
    // 获取失败，降级为手动签到
  },
  {
    enableHighAccuracy: true, // 高精度模式
    timeout: 8000,            // 超时时间
    maximumAge: 10000         // 缓存时间
  }
);
```

## 注意事项

1. **位置权限**：地理围栏签到需要用户授权浏览器位置权限
2. **HTTPS要求**：Geolocation API仅在HTTPS环境下可用
3. **精度问题**：GPS精度受环境影响，建议围栏半径设置不小于50米
4. **降级策略**：系统会自动处理位置获取失败的情况，不会阻止签到
5. **隐私保护**：位置信息仅用于签到验证，不会用于其他用途
